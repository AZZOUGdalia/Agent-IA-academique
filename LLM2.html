The Concept

🔴 The Challenge
  • Scattered courses (multiple PDFs).
  • Inefficient "Ctrl+F" search.
  • Confidential data (no Cloud).
🟢 The Solution
  • Semantic search engine.
  • Generated and sourced answers.
  • 100% Offline (Ollama + Chroma).

Technical Architecture

graph LR Files[PDFs] -->|Transformation| Vector[(ChromaDB Base)] User -->|Question| Core[rag_core] Core -->|Search| Vector Core -->|Context| Ollama[Llama 3.2]
  • Transformation: The PDF becomes a list of numbers (vectors).
  • Local Storage: vectorstore/ folder (hard drive).
  • Speed: Everything runs on the processor (CPU).
  • Independence: Works without Internet (Airplane Mode).

4. Opening: rag_API.py


# Strict data validation
class ChatRequest(BaseModel):
    question: str
    history: Optional[List[dict]] = []

# Web access point
@app.post("/chat")
def chat_endpoint(request: ChatRequest):
    return query_rag(request.question, request.history)
  • Gateway: Creates a Web address to talk to the AI.
  • Control: Checks question format (Security).
  • Universal: Allows creating a future mobile application.
  • Standard: Uses FastAPI technology.
