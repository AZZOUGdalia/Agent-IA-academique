🎓 Agent IA AcadémiqueCe projet est un assistant universitaire intelligent qui utilise le RAG (Retrieval-Augmented Generation) pour répondre aux questions basées sur vos cours et générer des quiz interactifs.🛠️ PrérequisPython 3.8+Ollama (Requis pour le modèle IA local)Téléchargez et installez depuis ollama.com.Ouvrez votre terminal et téléchargez le modèle requis :ollama pull llama3.2:3b
Assurez-vous que l'application Ollama tourne en arrière-plan.🚀 InstallationInstaller les dépendancesOuvrez un terminal dans le dossier du projet et lancez :pip install -r requirements.txt
💻 DémarragePour lancer l'application (Interface Web), utilisez cette commande exacte :python -m streamlit run rag_streamlit.py
Une fois lancée, l'application s'ouvrira automatiquement dans votre navigateur.FonctionnalitésChat Assistant : Posez des questions sur vos PDFs.Quiz Interactif : Testez vos connaissances.Upload de fichiers : Chargez vos cours directement depuis la barre latérale.DépannageErreur "AI Engine Offline" : Vérifiez que vous avez bien lancé l'application Ollama (ollama serve).Erreur de port : Si le port est occupé, Streamlit vous proposera d'utiliser un autre port automatiquement.
