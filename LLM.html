Le Concept

🔴 Le Défi
  • Cours éparpillés (PDFs multiples).
  • Recherche "Ctrl+F" inefficace.
  • Données confidentielles (pas de Cloud).
🟢 La Solution
  • Moteur de recherche sémantique.
  • Réponses générées et sourcées.
  • 100% Offline (Ollama + Chroma).

Architecture Technique

graph LR Files[PDFs] -->|Transformation| Vector[(Base ChromaDB)] User -->|Question| Core[rag_core] Core -->|Recherche| Vector Core -->|Contexte| Ollama[Llama 3.2]
  • Transformation : Le PDF devient une liste de nombres (vecteurs).
  • Stockage Local : Dossier vectorstore/ (disque dur).
  • Rapidité : Tout s'exécute sur le processeur (CPU).
  • Indépendance : Fonctionne sans Internet (Mode Avion).

4. Ouverture : rag_API.py


# Validation stricte des données
class ChatRequest(BaseModel):
    question: str
    history: Optional[List[dict]] = []

# Point d'accès Web
@app.post("/chat")
def chat_endpoint(request: ChatRequest):
    return query_rag(request.question, request.history)
  • Porte d'entrée : Crée une adresse Web pour parler à l'IA.
  • Contrôle : Vérifie le format des questions (Sécurité).
  • Universel : Permet de créer une future application mobile.
  • Standard : Utilise la technologie FastAPI.
